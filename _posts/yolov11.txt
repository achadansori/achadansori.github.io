It’s used in applications from autonomous driving to security surveillance and has gained popularity due to its balance of speed and precision. YOLO 11.0 brings improved architectures, higher mAP (mean Average Precision), and easier deployment options for edge and cloud-based applications.

Using Pre-trained Models for Instant Detection
You’re now ready to test YOLO 11.0 with a pre-trained model. Let’s run a sample image detection:

Code: Running Detection on a Sample Image
import torch
from yolov11 import YOLO

# Load pre-trained model
model = YOLO('yolov11s.pt')  

# Load an image
img = 'path/to/your/image.jpg'

# Perform inference
results = model(img)

# Display results
results.show()
This code loads a pre-trained YOLO 11.0 model and performs object detection on an image. Run the code to see YOLO in action as it identifies objects in the image.

Preparing a Custom Dataset
If you want YOLO to detect specific objects, you’ll need a custom dataset. Here’s how to prepare it:

Steps to Label Your Dataset:
Gather Images representing the objects you want to detect.
Label the Images using a tool like LabelImg.
Split Data into training, validation, and test sets. A common split is 70% training, 20% validation, and 10% testing.
Save your labeled dataset in YOLO format, which consists of:

Images in a folder.
Become a member
Labels in .txt files with each line representing an object in the format [class x_center y_center width height].
Training YOLO 11.0 on Your Custom Dataset
Training YOLO 11.0 requires configuring the model with your data.

Configuration
Edit data.yaml: Create a data.yaml file specifying your dataset paths and classes.
train: /path/to/train/images
val: /path/to/val/images
nc: 2  # Number of classes
names: ['class1', 'class2']
2. Run Training Script: Execute the training script with customized parameters:

python train.py --img 640 --batch 16 --epochs 100 --data data.yaml --weights yolov11s.pt
This script trains YOLO 11.0 on your data, adjusting parameters like image size and batch size for better performance.

Evaluating Model Performance
After training, evaluate your model to understand its accuracy.

Code for Evaluation
Use the following command to calculate metrics like mAP, precision, and recall:

python val.py --data data.yaml --weights runs/train/exp/weights/best.pt  
This will output a summary of performance metrics to help you decide if further tuning is needed.

Implementing Real-Time Object Detection on Video Feeds
YOLO 11.0 shines in real-time applications, and you can run live detections on a video feed or webcam.

Code for Real-Time Detection
import cv2
from yolov11 import YOLO

# Load model
model = YOLO('runs/train/exp/weights/best.pt')

# Initialize webcam
cap = cv2.VideoCapture(0)

while True:
    ret, frame = cap.read()
    if not ret:
        break

    # Run YOLO detection
    results = model(frame)
    results.show()  # Display the frame with detections

    # Press 'q' to exit
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

cap.release()
cv2.destroyAllWindows()
Deploying Your Model for Real-World Use
Once trained, deploy your YOLO 11.0 model to any environment using Docker for easier management and scaling.

Deploying with Docker
Create a Dockerfile:
FROM python:3.8-slim

# Copy YOLO 11.0 files and requirements
COPY . /yolov11
WORKDIR /yolov11

RUN pip install -r requirements.txt

# Command to run inference script
CMD ["python", "detect.py", "--source", "0"]  
2. Build and Run the Container:

docker build -t yolov11-detection .
docker run --gpus all -it yolov11-detection
You can replace the source with detect.py --source 0 for a webcam or point it to a folder of images for batch inference.
